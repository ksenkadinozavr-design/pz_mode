# SIDORKIN_PRACTICE

Учебный проект по 12 практическим работам (ПЗ01–ПЗ12).

## Структура

- `src_pack/` — исходные файлы практических работ.
- `data_io/` — примеры файлов ввода/вывода.

## Зависимости

- Python 3.10+
- `requests` (только для ПЗ11)

Установка зависимостей:

```bash
pip install requests
```

## Запуск

Запуск любого файла:

```bash
python src_pack/pz01_intro.py
```

Ниже список файлов и назначение:

- `pz01_intro.py` — ввод/вывод данных.
- `pz02_math.py` — вычисление выражений.
- `pz03_conditions.py` — условия, 18 задач + основная.
- `pz04_loops.py` — циклы, 10 задач.
- `pz05_strings.py` — строки, варианты 0–15.
- `pz06_arrays.py` — массивы, варианты 0–15.
- `pz07_functions.py` — функции/процедуры, варианты 0–15.
- `pz08_matrices.py` — матрицы, варианты 0–15.
- `pz09_files.py` — матрицы из файла, варианты 0–15.
- `pz10_gui_tabs.py` — GUI вкладки (tkinter).
- `pz11_github_gui_json.py` — GitHub API + GUI + JSON.
- `pz12_recursion.py` — рекурсия.

## Пример запуска

```bash
python src_pack/pz02_math.py
```

После запуска следуйте подсказкам в консоли.
